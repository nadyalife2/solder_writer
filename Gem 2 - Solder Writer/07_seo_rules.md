# SEO и AI-поиск

Цель — попасть в топ Яндекса, удержать читателя и быть процитированным AI-поиском.

## Title и H1

- Главный ключевой запрос — в первых 3–4 словах.
- Title до 60 символов, H1 можно чуть длиннее.
- Год ставь только если тема реально меняется каждый год (рейтинги, цены).
- Title и H1 совпадают или отличаются на 1–2 слова.

✅ «Как паять паяльником: пошаговая инструкция для начинающих»  
❌ «Всё о пайке — полное руководство мастера»

## Meta description

- До 160 символов.
- Ответ на вопрос заголовка + ключевое слово + польза.
- Не копируй первый абзац дословно.

Пример: «Как правильно паять паяльником: температура, флюс, шаги для новичка. Объясняем просто — без лишней теории.»

## Структура под Яндекс

- Первый абзац — прямой ответ на вопрос заголовка. Не «в этой статье разберём».
- Ключевой запрос: в H1, в первом абзаце, в одном-двух H2, в мета-описании. Не больше.
- H2/H3 — реальные вопросы пользователя, не красивые фразы.
- FAQ в конце закрывает дополнительные интенты и попадает в колдунщик Яндекса.

## Длина по типу кластера

| Тип кластера | Объём |
|---|---|
| Практический гайд / инструкция | 2000–3000 слов |
| Buyer's guide / рейтинг | 1500–2500 слов |
| Обучающий / «что такое» | 800–1500 слов |
| Проблема → решение | 1000–2000 слов |
| Сравнение | 1200–2000 слов |

Не пиши ради объёма — каждое предложение должно нести пользу.

## Внутренняя перелинковка

- Минимум 2 внутренние ссылки на смежные кластеры.
- Анкор — описание статьи, не «нажмите здесь».

Пример: «Подробнее о выборе флюсов — в отдельном гайде по материалам».

## Уникальность содержания

Яндекс ценит информационную ценность, а не уникальность по тексту. В каждой статье минимум один факт, которого нет у конкурентов:

- конкретная цифра: температура, время, мощность;
- ошибка, которую не разбирают dns-shop и habr;
- сравнение с реальными марками: ПОС-61, SAC305;
- подводный камень, которого нет в базовых гайдах.

Источник — лист raw_data из semantic_core. Не выдумывай данные.

## Правила для AI-поиска (Яндекс нейроответы и др.)

AI-поиск вырезает короткие самодостаточные фрагменты. Помогай ему:

- Первые 1–2 предложения сразу отвечают на вопрос заголовка — без разгона.
- После каждого важного H2 — ответ-блок 1–3 предложения, понятный без контекста.
- Формулируй утверждение прямо: «ПОС-61 плавится при 183 °C», а не «температура плавления ПОС-61 составляет…»
- H2 и H3 — как реальные вопросы пользователя: «Какой припой выбрать новичку», «Нужно ли смывать флюс после пайки».
- Для сравнений — таблица, для инструкций — нумерованные шаги, для признаков и ошибок — маркированные списки.
- FAQ: 4–6 вопросов в разговорной форме, каждый ответ понятен без контекста сверху.

Примеры хороших вопросов для FAQ:
- «Какой припой выбрать новичку?»
- «Нужно ли смывать флюс после пайки?»
- «Почему припой скатывается в шарик?»
- «Можно ли паять без флюса?»
- «Чем отличается ПОС-61 от бессвинцового припоя?»

## Запрещено

- Повторять ключ 5+ раз подряд.
- Заголовки только ради SEO без пользы для читателя.
- Кликбейт: «Вы не поверите, как паяют профи».
- Дублировать мета-описание между статьями.
- Прятать главный ответ ниже первого экрана.
