# SEO-правила

Цель — попасть в топ Яндекса и удержать читателя на странице.

## Title и H1

- Title и H1 должны совпадать или быть близки (1–2 слова разницы).
- Главный ключевой запрос — в первых 3–4 словах заголовка.
- Title до 60 символов, H1 можно чуть длиннее.
- Не ставь год в H1 без необходимости — он протухает. Ставь только если тема действительно ежегодно меняется (рейтинги, цены).

Примеры:
- ✅ «Как паять паяльником: пошаговая инструкция для начинающих»
- ❌ «Всё о пайке — полное руководство мастера»

## Meta description

- До 160 символов.
- Ответ на вопрос заголовка + ключевое слово + польза.
- Не копировать первый абзац статьи дословно.

Пример: «Как правильно паять паяльником: температура, флюс, шаги для новичка. Объясняем просто — без лишней теории.»

## Структура статьи под Яндекс

- Первый абзац — прямой ответ на вопрос заголовка (не «в этой статье разберём»).
- Ключевой запрос: в H1, в первом абзаце, в одном-двух H2, в мета-описании. Не больше.
- Подзаголовки H2/H3 — реальные вопросы пользователя, а не красивые фразы.
- FAQ в конце закрывает дополнительные интенты и попадает в колдунщик Яндекса.

## Длина статьи по типу кластера

| Тип кластера | Рекомендуемый объём |
|---|---|
| Практический гайд / инструкция | 2000–3000 слов |
| Buyer's guide / рейтинг | 1500–2500 слов |
| Обучающий / «что такое» | 800–1500 слов |
| Проблема → решение | 1000–2000 слов |
| Сравнение | 1200–2000 слов |

Не пиши ради объёма — каждое предложение должно нести пользу.

## Внутренняя перелинковка

- В каждой статье минимум 2 внутренние ссылки на смежные кластеры.
- Анкор — это описание статьи, а не «нажмите здесь» или «подробнее».
- Пример: «Подробнее о выборе флюсов — в отдельном гайде по материалам».

## Уникальность содержания

Яндекс ценит информационную ценность, а не уникальность по тексту.
В каждой статье должен быть минимум один факт или нюанс, которого нет у конкурентов:
- конкретная цифра из практики (температура, время, мощность);
- разбор ошибки, которую не описывают dns-shop и habr;
- сравнение материалов с реальными марками (ПОС-61, SAC305);
- предупреждение о подводном камне, которого нет в базовых гайдах.

Источник фактов — лист raw_data из semantic_core. Не выдумывай данные.

## Запрещено

- Искусственно повторять ключ 5+ раз подряд.
- Делать заголовки только ради SEO без пользы для читателя.
- Кликбейт: «Вы не поверите, как паяют профи».
- Дублировать мета-описание между статьями.
